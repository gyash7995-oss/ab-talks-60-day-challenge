# AB Talks — 60-Day Coding Challenge

A mobile-first student experience designed for the **AB Talks 60-Day Coding Challenge** as part of the **AB Hackathon VIBE CODED
**.

## Hackathon Brief

AB Talks runs a 60-day coding challenge for Indian college students.

Students choose a track, build something every day, and maintain a public learning streak by submitting:

- A GitHub commit
- A LinkedIn post

The hackathon asked for three core screens:

1. Landing Page
2. Student Dashboard
3. Challenge Day

The project is designed primarily for a **390px mobile viewport**.

## What I Built

This project focuses on making the daily challenge experience clear, simple, and motivating for students.

### Landing Page

`/`

Introduces AB Talks and the 60-day challenge to a new student.

### Student Dashboard

`/dashboard`

Shows the most important information a student needs, including:

- Current streak
- Today's task
- Challenge progress
- Overall completion
- Student standing and achievements

### Challenge Day

`/day/12`

Provides the complete experience for one challenge day, including:

- Daily task
- What needs to be built
- GitHub repository/commit proof
- LinkedIn post proof
- Submission readiness
- Submission flow

## Vibe Coding

This project was built using an **AI-assisted vibe-coding workflow**.

I used **Google Antigravity** with detailed natural-language prompts to generate, review, and refine the project.

The process included:

- Understanding the hackathon brief
- Planning the UI/UX
- Building the interface with AI prompts
- Reviewing the generated code
- Improving responsiveness
- Improving accessibility
- Checking SEO and performance
- Testing the required routes
- Refining the final implementation

The goal was to use AI as a development tool while still reviewing and improving the generated project.

## Design Approach

The project follows a **mobile-first** approach, with 390px as the primary viewport.

The interface focuses on:

- Clear information hierarchy
- Simple navigation
- Fast and lightweight interactions
- Clean UI
- Easy access to daily tasks
- Clear proof-of-work submission
- Responsive design
- Accessibility

Only the required hackathon experiences are included. No unnecessary product features were added.

## Tech Stack

- React

- JavaScript
- HTML
- CSS
- React Router
- Mock JSON data
- Vercel

Authentication, backend services, real user accounts, and a production database were not required by the hackathon, so the project uses mocked data.
